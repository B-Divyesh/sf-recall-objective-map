Privacy

Effective 28 August 2026. Recall Objective Map is local-first. Objectives, recall answers, and evidence notes are stored in your browser’s IndexedDB (or localStorage fallback) and are not sent to us.

Data you control

You can export all learning records as JSON and the weak-skill map as CSV. Import replaces the current local map only after confirmation. Removing this site’s browser data erases your local records; keep an export if you need a backup.

Purchases

If you choose the optional Field Kit, checkout and license verification are handled by the Sociobot billing API and its merchant of record, Dodo. This app stores the returned license token and a dated verification result in localStorage. It does not receive card details. See Sociobot’s checkout for its applicable privacy terms.

Network use

The app has no analytics, advertising, third-party fonts, or tracking scripts. After installation it works offline. The only optional third-party request is a license verification when a license is present, at most once per day.

Contact

Questions can be raised through the project’s public source repository linked from the app.
